# Security Policy

## Supported Versions

Only the latest release version of TickBudget is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within TickBudget, please report it responsibly:

* **Do not** open a public issue.
* Send an email with details of the vulnerability to `dabinayo@pm.me` or create a private security advisory on GitHub.
* Please include steps to reproduce, impact assessment, and any affected configurations.

We will acknowledge receipt within 48 hours and work with you on a timely resolution.
